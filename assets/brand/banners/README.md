## Hướng Dẫn Xuất Ảnh (Export to PNG)
1. Mở file HTML trong Google Chrome hoặc Edge.
2. Nhấn `F12` (Mở DevTools) -> Nhấn `Ctrl + Shift + P` -> Gõ `Capture node screenshot` hoặc chụp toàn màn hình với tỷ lệ 100% để có hình ảnh độ phân giải cao, sắc nét.
